# Yapı Ön Boyutlandırma (Blokmaci)

Çelik ve betonarme yapılar için tarayıcıda çalışan ön boyutlandırma, 3B modelleme ve metraj aracı.

## Özellikler
- Çelik Yapı / Betonarme Yapı seçimi
- Düzenlenebilir 3B model
- Beton (m³), kalıp (m²), donatı (kg/ton) ve grobeton (m³) metrajı
- Yönetmelik koşullarına göre geometrik kontroller ve uyarılar (TBDY, TS 500, TS 498, Çelik Yapılar Yönetmeliği)
- EXPORT: Excel (.xlsx) malzeme listesi

## Kullanım
`index.html` dosyasını tarayıcıda açın. İnternet bağlantısı gerekir (3B kütüphanesi CDN'den yüklenir).

GitHub Pages ile yayınlamak için: Settings → Pages → Branch: `main` / `(root)`.

## Not
Sonuçlar ön boyutlandırma amaçlıdır; nihai proje için yetkili mühendis kontrolü gereklidir.
